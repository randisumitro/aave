## Overview

The Edit Decision List (EDL) is a structured editing plan generated by the Creative Decision Engine and validated before execution in Premiere Pro or After Effects. The EDL uses JSON Schema (draft-07) for validation.

## EDL JSON Schema

**Schema ID:** `https://aave.randisumitro.dev/schemas/edl/v1`  
**Version:** 1.0.0  
**Schema:** JSON Schema draft-07

### Top-Level Structure

```json
{
  "version": "1.0.0",
  "project": { ... },
  "creative_direction": { ... },
  "timeline": [ ... ],
  "audio": { ... },
  "graphics": { ... },
  "metadata": { ... }
}
```

### Required Fields

| Field | Type | Description |
|-------|------|-------------|
| `version` | string | Must be `"1.0.0"` |
| `project` | object | Project settings |
| `creative_direction` | object | Creative direction |
| `timeline` | array | Non-empty array of edit decisions |

### Project Settings

| Field | Type | Required | Constraints | Description |
|-------|------|----------|-------------|-------------|
| format | string | Yes | vertical\|square\|horizontal | Output format |
| width | integer | Yes | >= 1 | Video width in pixels |
| height | integer | Yes | >= 1 | Video height in pixels |
| fps | integer | Yes | >= 1 | Frames per second |
| target_duration | integer | Yes | 15-90 | Target duration in seconds |
| aspect_ratio | string | Yes | 9:16\|1:1\|16:9 | Aspect ratio |

Default: 1080x1920, 30fps, 45s, 9:16 vertical

### Creative Direction

| Field | Type | Required | Constraints | Description |
|-------|------|----------|-------------|-------------|
| style | string | Yes | - | Editing style (e.g. "dynamic_ugc") |
| pace | string | Yes | slow\|medium\|fast | Editing pace |
| tone | string | Yes | - | Emotional tone (e.g. "engaging") |
| hook_strength_threshold | number | No | 0-1 | Minimum hook strength score |

### Timeline (Edit Decisions)

Each timeline entry represents a clip placement:

| Field | Type | Required | Constraints | Description |
|-------|------|----------|-------------|-------------|
| id | string | Yes | - | Unique edit decision ID |
| source | string | Yes | - | Source media file path or ID |
| source_in | number | Yes | >= 0 | In point in source (seconds) |
| source_out | number | Yes | >= 0, > source_in | Out point in source (seconds) |
| timeline_start | number | Yes | >= 0 | Start position on timeline (seconds) |
| role | string | Yes | hook\|context\|b_roll\|ending | Narrative role |
| transition | string | No | - | Transition type |
| duration | number | Yes | >= 0 | Clip duration on timeline |

### Audio

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| music | string | No | Music track reference |
| ducking | boolean | No | Enable audio ducking |
| sound_effects | array | No | Array of sound effect placements |

**Sound Effect Item:**
| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| timestamp | number | Yes | >= 0 |
| type | string | Yes | SFX type |
| volume | number | Yes | 0-1 |

### Graphics

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| captions | boolean | No | Enable captions |
| motion_titles | boolean | No | Enable motion titles |
| lower_thirds | boolean | No | Enable lower thirds |
| kinetic_typography | boolean | No | Enable kinetic typography |

### Metadata

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| generated_by | string | Yes | Generator identifier |
| generated_at | string | Yes | ISO 8601 timestamp |
| source_footage | string[] | Yes | List of source footage paths |
| total_duration | number | Yes | >= 0 |

## Validation Rules

The `validateEDL()` function performs the following checks:

1. **Version check**: EDL version must be `"1.0.0"`
2. **Project check**: All required project fields must be present
3. **Aspect ratio**: Must be one of `"9:16"`, `"1:1"`, `"16:9"`
4. **Creative direction check**: All required fields must be present
5. **Timeline check**: Must be a non-empty array
6. **Entry validation**: Each timeline entry must have all required fields
7. **Role validation**: Must be one of `hook`, `context`, `b_roll`, `ending`
8. **Time validation**: `source_out` must be greater than `source_in`

## Example EDL

```json
{
  "version": "1.0.0",
  "project": {
    "format": "vertical",
    "width": 1080,
    "height": 1920,
    "fps": 30,
    "target_duration": 45,
    "aspect_ratio": "9:16"
  },
  "creative_direction": {
    "style": "dynamic_ugc",
    "pace": "fast",
    "tone": "engaging",
    "hook_strength_threshold": 0.7
  },
  "timeline": [
    {
      "id": "edit_001",
      "source": "/footage/intro.mp4",
      "source_in": 0,
      "source_out": 5,
      "timeline_start": 0,
      "role": "hook",
      "duration": 5,
      "transition": "fade_in"
    },
    {
      "id": "edit_002",
      "source": "/footage/main.mp4",
      "source_in": 10,
      "source_out": 20,
      "timeline_start": 5,
      "role": "context",
      "duration": 10
    }
  ],
  "audio": {
    "music": "/audio/background.mp3",
    "ducking": true,
    "sound_effects": [
      {
        "timestamp": 0,
        "type": "whoosh",
        "volume": 0.5
      }
    ]
  },
  "graphics": {
    "captions": true,
    "motion_titles": true,
    "lower_thirds": true,
    "kinetic_typography": false
  },
  "metadata": {
    "generated_by": "AAVE Creative Decision Engine",
    "generated_at": "2026-11-21T05:00:00+07:00",
    "source_footage": ["/footage/intro.mp4", "/footage/main.mp4"],
    "total_duration": 45
  }
}
```

## Validation Helper (TypeScript)

```typescript
import { validateEDL } from "@aave/edit-decision-schema";

const result = validateEDL(edlObject);
if (!result.valid) {
  console.error("EDL validation errors:", result.errors);
}
```
